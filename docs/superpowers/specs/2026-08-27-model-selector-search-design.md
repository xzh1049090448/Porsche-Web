# 模型选择器模糊搜索设计

## 目标

在聊天页模型选择面板增加一个本地搜索框，使用户可按关键词快速筛选动态授权模型目录；单模型选择与对比模式的多选列表使用同一搜索结果。

## 交互

- 搜索框位于模型选择面板的模型列表上方，模型目录加载成功后显示。
- 输入即时生效，不请求后端、不修改模型目录、ACL 或缓存。
- 匹配模型 `name`、`id`、`vendor`、`desc` 的任一字段；使用 Unicode 安全的大小写不敏感子串匹配。
- 空关键词显示完整目录；无匹配时在单选与对比区域显示明确空态。
- 同一过滤结果同时驱动单模型按钮列表和对比模式复选框列表。

## 状态与边界

- 搜索关键词仅为组件临时状态，不写入 localStorage、URL 或后端。
- 已选单模型和已选对比模型不会因为搜索过滤而被清除；清空搜索后会重新显示。
- 现有动态目录、后端授权边界、详情加载、比较模式开关以及最多 3 个对比模型的限制保持不变。
- 模型元数据继续以 Vue 文本绑定渲染；不新增 `v-html` 或原始 HTML 插入。

## 验收

1. 搜索模型名称、ID、厂商或简介的任意部分，都能在单选和对比列表中得到相同过滤结果。
2. 大小写不同的英文关键词仍可匹配；空关键词恢复所有授权模型。
3. 无匹配时显示空态，已选模型和比较上限不被改变。
4. 前端单元测试、`npm test`、`npm run build` 与 `git diff --check` 通过。
