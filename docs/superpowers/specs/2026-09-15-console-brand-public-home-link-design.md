# 后台品牌链接跳转公共首页设计

**状态：** APPROVED_FOR_IMPLEMENTATION

**日期：** 2026-09-15

## 目标

用户进入已登录控制台后，点击左上角品牌标识，应通过 Vue Router 在当前标签页进入公共首页 `/`。

## 设计

- 修改共享组件 `src/components/shell/AppBrand.vue`，将现有 `/chat` 目标改为 `/`。
- 保留现有品牌图标、标题、副标题、样式和无障碍名称。
- 继续使用 `router-link`，保持客户端路由切换和键盘链接语义。
- 不改变公共页页头、后台侧边栏、认证状态或退出登录行为。

## 验收

1. `AppBrand` 的唯一链接目标为 `/`。
2. 已登录控制台所有使用 `AppBrand` 的页面都获得相同行为。
3. 组件原有标题、副标题和样式契约保持不变。
