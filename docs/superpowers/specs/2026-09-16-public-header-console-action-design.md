# 公共首页页头与能力条视觉修正设计

## 目标

公共页面桌面端页头把“进入控制台”从左侧主导航移到右侧操作区，并放在语言切换和主题切换之后。桌面端顺序固定为“语言 → 主题 → 进入控制台”。同时，公共页头复用控制台的品牌组件和品牌文字，首页三列能力条补齐完整外框。

## 响应式行为

- 桌面端（`min-width: 768px`）：左侧主导航只保留产品优势、支持模型、模型价格和关于；控制台入口显示在主题按钮右侧。
- 移动端（`max-width: 767px`）：右侧操作区继续只显示语言和主题按钮；控制台入口保留在折叠菜单中，避免挤压页头。
- 两个响应式入口都指向 `/chat`，任一视口只展示一个可交互入口。

## 可访问性与交互

- 保持现有 `RouterLink`、按钮文案和 `public-console-cta` 语义。
- 移动端入口继续参与菜单焦点循环，并在导航后关闭菜单。
- 桌面端 DOM 顺序与视觉顺序一致：语言按钮、主题按钮、控制台链接。
- 隐藏的响应式入口使用 `display: none`，不进入键盘焦点顺序。

## 品牌统一

- 公共页头直接复用控制台的 `AppBrand` 组件，不再渲染独立的“AI”方块和 `Porsche` 文案。
- 图标统一使用 `/logo.png`。
- 中文品牌统一显示“中国大模型聚合平台 / 智谱 GLM / DeepSeek”；英文品牌统一显示“China LLM Hub / Zhipu GLM / DeepSeek”。
- 品牌组件的结构和基础样式提升为公共与控制台共享样式；点击品牌仍进入公共首页 `/`。

## 能力条边框

- `.public-proof` 从仅有上、下边框调整为完整四边外框。
- 桌面端三列内部继续使用竖向分隔线。
- 移动端继续使用横向分隔线，最后一项不重复绘制底部分隔线。
- 不改变能力条内容、列数、间距和响应式堆叠方式。

## 实现范围

- 调整 `PublicHeader.vue` 的导航和操作区渲染结构，并复用 `AppBrand`。
- 在 `public-shell.scss` 增加桌面、移动端入口的显示规则。
- 将品牌结构所需样式放入公共与控制台都会加载的基础样式，并删除控制台中的重复定义。
- 在 `public-content.scss` 为首页能力条补齐完整外框。
- 补充公共品牌副标题的中英文文案和公共运行时读取方法。
- 更新公共页头合同测试，验证桌面端位置、移动端位置、唯一可见入口及 `/chat` 路由。
- 不改变控制台路由、文案、主题逻辑、语言逻辑或其他公共页面布局。

## 验收标准

1. 1280px 桌面视口中，“进入控制台”位于主题按钮右侧。
2. 桌面主导航中不再出现控制台入口。
3. 390px 移动视口中，顶部操作区没有控制台入口，展开菜单后可见该入口。
4. 桌面和移动端均只有一个可见且可聚焦的控制台入口。
5. 公共页头与控制台使用相同的 `/logo.png`、标题、副标题和 `AppBrand` 结构。
6. 三列能力条具有完整四边外框，并保留正确的桌面和移动端内部分隔线。
7. 公共页头合同测试和相关公共页面测试全部通过。
