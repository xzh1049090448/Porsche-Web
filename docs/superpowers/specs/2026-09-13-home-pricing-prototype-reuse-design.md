## 目标

将公开主页按以下原型的布局、样式、动画和区块顺序忠实迁移到现有 Vue 应用：

- `/Users/xuzhihao/Doubao/chats/2026-09-01/new-chat-1/landing-prototype.html`

将公开价格页按以下原型重组：

- `/Users/xuzhihao/Doubao/chats/2026-09-01/new-chat-1/pricing.html`

同时把该目录五个原型共有的轻量交互节奏应用到全站路由切换，并统一缩小公共页、认证页、控制台、用户管理和 Root 后台的字号。

## 已确认的产品决定

1. 采用 Vue 原生忠实迁移，不用 iframe、Tailwind CDN 或独立静态页。
2. 复用原型的结构、间距、配色、阴影、动画和响应式布局；品牌改为 Porsche/当前产品品牌，链接接入真实 Vue 路由。
3. 不复制 `ModelHub`、`40+`、`MIT License`、供应商数量、分组倍率、演示凭据或其他未经确认的原型数据。
4. 主页和价格页继续消费现有发布快照及公开价格接口；加载、空、准备中、错误与权限状态保持真实。
5. 全站路由内容使用“约 200ms 淡出，再约 350ms 淡入”的 `out-in` 过渡；固定导航、侧栏与全局提示不参与页面内容动画。
6. 主页锚点使用平滑滚动；启用 `prefers-reduced-motion: reduce` 时立即切换和滚动。
7. 全站采用紧凑字号标尺：主页 Hero 桌面 44px/移动 34px；普通页面标题 18–20px；正文、表格、表单、按钮 14px；辅助信息与状态 11–12px。触控高度仍至少 44px。

## 页面架构

### 公共主页

主页保留 `PublicLayout`、`PublicHeader`、`PublicFooter` 和当前发布数据生命周期。`Home.vue` 按原型顺序重组为：

1. 56px 固定/粘性公共导航；品牌、优势、模型、价格、关于及控制台使用真实路由。
2. 点阵与柔和色块背景的双栏 Hero；左侧使用发布标题与简介，右侧使用无网络副作用的产品预览插图。
3. 三列能力摘要；只使用可验证的定性能力，不显示未经确认的数量或协议。
4. 白色优势区；发布的优势内容映射为三列卡片。
5. 浅灰模型区；模型墙使用发布快照中的 `modelKey`、显示名称、供应商和受控资源。
6. 公告/FAQ 信息区；内容为空时显示现有空态。
7. 蓝色 CTA；跳转真实 `/chat` 与 `/pricing`。
8. 深色页脚；链接到真实关于、条款与隐私页面。

Hero 预览是视觉插图，不发送请求、不消耗 Token，也不作为真实对话记录。公告对话框的读取标记、Escape、焦点约束和关闭后焦点恢复保持不变。

### 公开价格页

价格页保留现有 store、认证升级、canonical query、请求取消、缺价规则和稳定 `modelKey`。呈现结构按 `pricing.html` 调整为：

1. 与主页一致的公共导航。
2. 最大宽度 1600px 的紧凑双栏工作区。
3. 左侧 260px 粘性筛选卡；包含搜索、公开分组、供应商、能力和端点类型。只展示接口实际返回的 facet。
4. 右侧标题、结果数量、搜索/排序工具栏和紧凑价格表。
5. 表格列保留模型、供应商、输入价格、输出价格、上下文、能力、端点；不增加单次调用价。
6. 移动端把筛选栏改为对话框式抽屉、表格改为价格卡；保留焦点约束、Escape 关闭和关闭后焦点恢复。
7. 加载、认证要求、空、错误和分页状态继续由当前状态机控制。

原型中的固定模型、供应商数量、倍率、按次价格和收藏按钮不进入产品实现。

## 路由切换

新增一个纯呈现的共享路由过渡组件，在需要动画的 `RouterView` outlet 外层使用 Vue `Transition`：

- 公共布局的子路由出口负责 `/`、`/pricing`、详情、关于、条款、隐私与 404。
- 认证入口负责登录、注册和控制台布局之间的顶层切换。
- 控制台主内容出口负责聊天、账单、API 密钥、个人中心、用户管理及 Root 后台页面。

组件使用 route leaf key 和既有身份 epoch，保持身份切换时强制重建。过渡只修改 opacity，不使用 transform，避免影响 fixed/sticky 子元素和对话框定位。路由守卫先完成鉴权与重定向，再开始目标内容进场。快速连续导航时以最新已确认路由为准，不修改 API 请求所有权或取消语义。

同页 hash 导航不销毁页面，只执行平滑滚动。滚动结束后把程序焦点移到目标标题；若目标不存在则聚焦主内容。浏览器前进/后退保留路由滚动位置，普通新页面导航回到顶部。

## 全站字体系统

在共享 token 中增加语义字号并映射公共页面、控制台和 Element Plus：

| 令牌 | 尺寸 | 用途 |
| --- | ---: | --- |
| `--font-size-xs` | 11px | 极小标注、时间、次要元数据 |
| `--font-size-sm` | 12px | 标签、状态、辅助说明 |
| `--font-size-body` | 14px | 正文、表格、表单、按钮、导航 |
| `--font-size-subtitle` | 16px | 卡片标题、对话框标题 |
| `--font-size-page-title` | 20px | 普通页面标题 |
| `--font-size-section-title` | 30px | 公共主页区块标题 |
| `--font-size-hero` | 44px | 主页桌面 Hero |
| `--font-size-hero-mobile` | 34px | 主页移动 Hero |

本轮不使用 `zoom`、`transform: scale` 或降低浏览器根字号。输入、按钮和分页触控尺寸仍至少 44px；危险操作确认框不因字体缩小而压缩确认内容。

## 数据、错误与安全边界

- 主页继续使用发布快照；未发布或缺失内容走现有 preparing/empty/error，不用原型 fixture 填充。
- 价格页继续使用公开价格权限、缺价规则、认证升级、canonical query、分页和 stale-request cancellation。
- `v-html` 内容继续只接收现有净化管线输出；危险 URL、远程媒体和受控资源规则不变。
- 路由动画不得绕过认证、Root-only 守卫、identity epoch、API/store 行为或危险操作确认。
- 生产构建不得引入 Tailwind CDN、原型文件、Mock 数据、演示凭据或原型中的死链接。
- P08 生产内容真实性仍由产品后续补充，本轮不把示例文案标为已批准生产内容。
