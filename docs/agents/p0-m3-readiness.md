| 编号 | 操作与预期 | 数据边界 |

| M3-01 | 核对发布 SHA/资源，HTTPS 同源；浏览器具备 Web Locks/BroadcastChannel、可写协调存储 | 不放宽 Cookie/CORS/Origin |
