# A09-A12 交付计划

## 范围

- A09：在开发环境专用入口展示合成用户的 CNY 余额、累计已用、增减/扣减/覆盖预览和 Mock 调整记录。
- A10：用内存夹具演示成功、失败、超时、版本冲突和重复提交；任何失败都不改变余额或记录。
- A11：生产构建不注册演示路由、不包含演示模块标记；真实用户列表和详情继续显示“金额功能未接入”，后端不存在真实调额写路由。
- A12：复验既有 `users.delete` 软删除切片的重复删除、用户名永久占用、凭据失效和只读墓碑证据，不重复实现删除链路。

## 实施顺序

1. 先用纯领域测试冻结整数分计算、输入上限、余额不足和幂等语义。
2. 实现开发环境专用内存夹具和演示页面，入口固定为 `/demo/admin/balance`。
3. 增加生产构建产物扫描以及后端伪造调额路径拒绝测试。
4. 运行前端全量、生产构建、后端全量及 A12 定向回归，再更新两端验收矩阵。

## 边界

- 不增加余额、账本、充值、退款、扣费或调额数据库表与接口。
- 不读取真实用户、不采集管理员密码、不写正式管理审计或浏览器持久化。
- 本轮不推送、不部署、不执行生产迁移。
